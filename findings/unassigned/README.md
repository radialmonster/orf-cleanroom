# unassigned/

Bitstream findings whose variant isn't known yet. Use `Variant: unassigned`.

Format, file names and rules: [../README.md](../README.md).
Variant definitions: [VARIANTS.md](../../VARIANTS.md#assigning-a-variant).

## Findings here
Verified findings are the dated files in this folder (`python tools/findings_index.py` lists them). A verified finding is a lead reproduced in a second, separate run; it is added here by the verifier's PR. Open leads for this folder are issues labelled `lead` (https://github.com/radialmonster/orf-cleanroom/issues?q=is%3Aopen+label%3Alead). `python tools/findings_index.py` lists what is here.
